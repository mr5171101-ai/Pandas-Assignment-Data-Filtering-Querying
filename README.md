# Student Data Analysis (Pandas 50 Questions) 📊

This project demonstrates data manipulation and filtering on a student marksheet dataset using Python's **Pandas** library.

## 🚀 Project Overview
The main goal is to solve **50 data filtering and analytics questions** based on various programming subjects (Python, NumPy, Pandas, ML, DL, NLP, Streamlit).

### 🛠️ Key Pandas Techniques Used:
* **Conditional Selection:** Filtering data using single and multiple conditions (`&`, `|`).
* **Range Filtering:** Using `.between()` to find scores in specific ranges.
* **Statistical Analysis:** Applying `.max()`, `.min()`, and `.mean()` for advanced insights.
* **Row-wise Checks:** Tracking outliers using `.any(axis=1)`.

## 💻 How to Run
1. Clone the repository.
2. Install Pandas: `pip install pandas`
3. Run the script: `python main.py`
